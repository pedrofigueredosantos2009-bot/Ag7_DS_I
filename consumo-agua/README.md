 Consumo de Água

 Sobre o projeto

O Consumo de Água é um programa desenvolvido em Python para classificar o perfil de consumo de água de diferentes tipos de imóveis.

O sistema recebe o tipo do imóvel e o consumo mensal de água em metros cúbicos (m³) e apresenta uma mensagem educativa de acordo com o consumo informado.

 Objetivo

O objetivo do projeto é praticar a utilização de estruturas condicionais em Python e desenvolver um programa relacionado à conscientização sobre o consumo de água.

 Tipos de imóveis

*  Comercial
*  Casa
*  Apartamento

 Regras do sistema

*  Imóvel comercial: exibe uma mensagem sobre a tarifa comercial.
*  Apartamento com consumo menor que 10 m³: consumo econômico.
*  Apartamento ou casa com consumo de até 25 m³: consumo moderado.
*  Outros casos: consumo excessivo.
